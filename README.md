# 📉 Customer Churn Analytics Dashboard

## 📌 Overview

This project is an interactive Customer Churn Analytics Dashboard built using **Power BI**. It helps businesses understand customer churn patterns, identify high-risk customer segments, and monitor key retention metrics through interactive dashboards.

## 📈 Dashboard Features

- Churn Rate by Contract Type

---

## 💼 Business Insights

- Customer Churn Rate is approximately **13%**.
- Month-to-Month contracts have the highest churn.
- Fiber internet customers show higher churn than other service types.
- Active Customers represent more than **86%** of the customer base.
- Average Support Tickets per customer is **3**.
